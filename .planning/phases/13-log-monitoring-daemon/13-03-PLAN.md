    - Open `/proc/net/nf_conntrack` for reading line-by-line (iterate with `for line in f:`)

    - Wrap the entire open in `try/except OSError: return '✗'`
    - Return `'✗'` at the end if no matching line found
    - Note: `dpt` argument is a string (comes from the log line as DPT=N); use as-is in the `dport={dpt}` check

    - `import os; os.makedirs(LOG_DIR, exist_ok=True)`
    - `path = f"{LOG_DIR}/watch-{today.isoformat()}.log"`
    - `_log_file = open(path, "a", encoding="utf-8")`
    - `_log_date = today`
    - return `_log_file`

    `_write_daemon_line(line)` — thread-safe write to the current dated log file:
    - Acquire `_daemon_write_lock`
    - Call `f = _open_log_file()`
    - `f.write(line + "\n")`
    - `f.flush()` (mandatory — ensures line is visible to `tail -f` immediately)

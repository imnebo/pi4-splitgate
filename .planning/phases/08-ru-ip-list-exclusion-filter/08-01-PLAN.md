Insert the following block between the `source /etc/vpn-gateway.env` line and the
`# ─── Stage 1:` comment line. The block sets EFFECTIVE_URL, then conditionally appends
exclude params. Insert as a new named section using the established comment-bar style:

```
# ─── Build effective download URL (D-05, D-06) ───────────────────────────────
# If /etc/ru-exclude.txt exists and is non-empty, append &exclude[cidr4]=CIDR
# for each non-comment non-blank line. Absent or empty file → URL unchanged.
EFFECTIVE_URL="${RU_SUBNET_URL}"
EXCLUDE_FILE="/etc/ru-exclude.txt"
if [[ -f "${EXCLUDE_FILE}" ]]; then
    exclude_count=0
    while IFS= read -r line; do
        # Skip comment lines (starting with #) and blank lines (D-02)
        [[ "${line}" =~ ^# || -z "${line}" ]] && continue
        EFFECTIVE_URL="${EFFECTIVE_URL}&exclude[cidr4]=${line}"
        (( exclude_count++ )) || true
    done < "${EXCLUDE_FILE}"
    if (( exclude_count > 0 )); then
        log "Excluding ${exclude_count} CIDR(s) from RU subnet download"
    fi
fi
```

Then change line 40 from:
  `if ! curl -fsSL "${RU_SUBNET_URL}" -o "${SUBNET_TMP}" 2>/dev/null; then`
to:
  `if ! curl -fsSL "${EFFECTIVE_URL}" -o "${SUBNET_TMP}" 2>/dev/null; then`

No other lines are modified. The rest of the script (SHA256 compare, atomic mv,
routing.sh call) is unchanged per D-06.

Important: use `(( exclude_count++ )) || true` to avoid `set -e` triggering when
exclude_count is 0 before the first increment (arithmetic expansion returns exit code 1
when result is 0 in bash with set -e).

# Plan 09-01: Operational Logging

## Goal

Replace `logger`/echo-only logging in all daemon scripts with timestamped
file-append to `/etc/splitgate/logs/vpn-gateway.log`. Update teardown.

## Context

All decisions from `09-CONTEXT.md`. Log path adjusted to
`/etc/splitgate/logs/vpn-gateway.log` (Phase 10 D-19 override of Phase 9's
original `/var/log/vpn-gateway.log`).

logrotate config and deploy.sh Stage 27 already exist from Phase 10 — no
changes to those files needed.

| File | Change |
|------|--------|
| `src/scripts/routing.sh` | Upgrade `log()` + `err()` to timestamp + file-append |
| `src/scripts/update-vpn-routes` | Replace `logger -t "vpn-routes"` with file-append |

## Decisions Applied

- **D-03**: `log()` pattern: `echo "[$(date '+%F %T')] [component] $*" >> LOG_FILE`
- **D-04**: `err()` pattern: `echo "... ERROR: $*" | tee -a LOG_FILE >&2`
- **D-05**: All `logger -t tag` calls removed
- **D-06**: routing.sh log() upgraded (file-append replaces echo-only)
- **D-07**: Verbosity unchanged — all stages logged in routing.sh
- **D-08**: Interactive tools (vpn-status.sh) do NOT write to log file
- **D-11**: vpn-rollback.sh teardown removes `/etc/logrotate.d/vpn-gateway`
